# LMU: телеметрия живых игроков на руле — результаты поиска

Папка соответствует `D:\lmu-ai-data\human_telemetry_research\` из задания. В этой среде её нет, поэтому она лежит в репозитории по пути `lmu-ai-data/human_telemetry_research/`. Дата поиска: 2026-10-25.

## Главное

- **21 пригодный круг LMU с рулевой телеметрией** (из 25 кругов с телеметрией; 4 исключены как неполные). Один источник: `LMU-Tracking-Desktop/tracker` (MIT по README), одна машина/один игрок.
  - Spa-Francorchamps: 9 кругов (1 практика, 1 квалификация, 7 гоночных).
  - Imola: 8 кругов (включая 1 импортированный).
  - Sebring International: 3 (1 Hypercar, 2 GT3).
  - Paul Ricard 1A-V2: 1 (GT3).
  - Классы в данных как записано приложением: `GT3` = 20, `Hyper` = 1. Вероятно LMGT3 и Hypercar.
- **Не закрыто:** LMP2, LMP3, GTE — 0. Из 22 строк таблицы трасс и раскладок данные есть только у 4. Полная таблица в `coverage.md`.
- **Качество для обучения ограниченное.** Входы (руль, газ, тормоз, скорость, обороты) записаны примерно 15 раз в секунду. Позиция на круге и время обновляются примерно 5 раз в секунду, что ниже требуемых 10 Гц. Угол руля в градусах не записан (только нормализованный сигнал). Сцепления нет. Набор не выполняет требование «50–100 Гц».
- **Найден один rF2-лог с рулём и force feedback** (9 полных кругов, лучший 54.0 с, угол руля в градусах 20 Гц). Это не трасса LMU, поэтому он не закрывает ни одну дыру. Это резервный образец.
- **Публичных датасетов LMU не найдено.** Блокировки среды не позволили проверить Reddit, Overtake, Kaggle, Zenodo, Hugging Face, Steam, YouTube и официальный сайт LMU (подробно в `sources_checked.md`).

## Решения, которые стоит проверить

1. **Исходные файлы не коммитились** из-за имён людей в `dev.db` и в заголовке `.ld`. Это противоречит букве «raw без изменений», но не противоречит требованию не собирать данные о людях. Если вам нужны сами файлы, скажите, и я подумаю, как их положить безопасно.
2. **Ник в `source`.** В `author` записано «not stated», потому что в поле `source` указаны организация или владелец репозитория.
3. **Список трасс** собран по гайдам (traxion, racinggames, boxthislap, Coach Dave, onlineracedriver 2024). Официальный сайт и Steam недоступны из среды. Строки без подтверждения помечены «не подтверждено».
4. **Ввод «wheel» для LMU — вероятный.** Это вывод по распределению сигнала руля (аналоговость, плотность значений, почти нет насыщения на ±1). В файлах LMU нет force-feedback каналов, поэтому подтвердить нельзя. Один круг (OWN-010) имеет 5% сэмплов на полном угле, его стоит проверить отдельно.
5. **Версия LMU** в данных не записана. Сессии с телеметрией датированы 20.04–08.05.2026. Версия v1.3 вышла 31.03.2026; точная сборка неизвестна.
6. **Ветка.** Коммит в `claude/lmu-driver-telemetry-dataset-vgx56c`, как указано в задании. Pull request не создавался.

## Сетевые ограничения

Egress-прокси блокирует хосты с данными: Zenodo, Hugging Face, Kaggle, Figshare, OSF, Reddit, Overtake, YouTube, Steam, arXiv, Google Drive, Dropbox, Mega и сайты LMU (403 или недоступно). Обходов не делалось. Из GitHub читались 9 публичных репозиториев, которые были добавлены через `add_repo`. Три репозитория (`pavva94/LMUTelemetry`, `Herbertmt978/MoTeC-MCP`) не открылись: «not found or no access». GitLab и Codeberg не читались, потому что они вне scope. Поиск по GitHub через API и MCP за пределы scope не делался.

## Как воспроизвести

```
python3 -I scripts/derive_lmu.py <tracker>/prisma/dev.db derived/lmu_desktop_devdb
python3 -I scripts/derive_rf2.py "<путь>/2025-08-03 - 16-34-45 - Matsusaka East Circuit - P1.ld" derived/rf2_matsusaka_p1
python3 -I scripts/build_catalog.py <tracker>/prisma/dev.db derived catalog.csv
```

Скрипты читают файлы только для чтения. Код из скачанных файлов не запускается. Интерпретатор Python запускается с `-I`.
